# Day 4: Git Workflow

## Git Commands

### Check repository status
```bash
git status
```

### Create a new branch
```bash
git branch feature-update
```

### Switch to the new branch
```bash
git checkout feature-update
```

### Add changes
```bash
git add .
```

### Commit changes
```bash
git commit -m "Update project files"
```

### Merge a branch
```bash
git checkout main
git merge feature-update
```

### Delete a branch
```bash
git branch -d feature-update
```

## What I Learned

I learned how Git branches help developers work on different features and manage project changes.
