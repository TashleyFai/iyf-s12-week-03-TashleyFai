# Terminal Practice Log

## 1. Checking My Current Location

```bash
pwd
```
This command shows my current working directory.

## 2. Listing Files and Folders

```bash
ls
```
This command displays files and folders in the current directory.

## 3. Navigating Between Directories

```bash
cd ~/Documents
pwd
cd ..
pwd
cd ~
pwd
```
These commands help me move between directories.

## 4. Creating a Practice Folder

```bash
mkdir ~/terminal-practice
```
This command creates a folder called `terminal-practice`.

## 5. Checking Git Installation

```bash
git --version
```
This command checks whether Git is installed and displays its version.

## 6. What I Learned

I learned how to check my current directory, list files, navigate between folders, create directories and check my Git installation.

## 7. Challenges Faced

I experienced some errors when entering commands and creating folders. I learned to check my current location before running commands.
